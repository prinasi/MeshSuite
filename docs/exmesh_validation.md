# ExMesh 集成验收记录

环境：msbench / Python 3.12.15 / PyTorch 2.7.0+cu118 / Open3D 0.19.0，RTX 3060 12GB。
ExMesh 参考提交：`0bf121895ebd74642c1bab824a992c48f95296e8`。
安装和运行命令见 [exmesh.md](exmesh.md)，原始 JSON、日志和模型位于工作区 `outputs/`。

默认 `./single_train.sh exmesh dtu/scan24 0` 已切换为 2DGS 7000 步初始化与
ExMesh 8000 步、白背景 RGBA 合成的论文参数配置，其独立记录见 [论文参数复现](exmesh_paper_protocol.md)。
下述 PGSR / 10000 步历史结果不能作为新配置已复现论文的证据。

## DTU scan24

两套配置均完成 10,000 步，纹理为 2560×2560，均使用 DA3 预测深度。
初始化分别通过独立 PGSR 5,000 步生成，voxel=0.01、max_depth=5、num_cluster=1，不启用深度过滤。
基准初始化只用 42 个训练视图，不使用 7 个留出图像；其输入相机来自已提供的 COLMAP 标定。

| 配置 | 图像评测口径 | 分辨率 | PSNR ↑ | SSIM ↑ | LPIPS ↓ | DTU CD ↓ |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| 仓库复现配置 | 全部 49 个训练视图，黑背景，拟合指标 | 1554×1162 | 23.3290 | 0.8823 | 0.1410 | 0.4413 |
| MeshSuite 基准 | 42 训练 / 7 测试，白背景前景模式 | 777×581 | 22.3454 | 0.8283 | 0.1775 | 0.5395 |

两行采用不同的视图、背景、分辨率，不能把差值解释成单一因素的消融结果。
图像指标由 MeshSuite 公共 PSNR/SSIM/LPIPS 流程计算，LPIPS 使用 VGG。
几何评测均明确返回 `protocol=dtu_official`，使用 ObsMask、Plane、真值点云、
`cameras.npz` 的尺度转换和 mask 裁剪；CD 为 accuracy 与 completeness 的均值，单位为 DTU 的毫米。

| 配置 | 初始 CD | 最终 accuracy | 最终 completeness | 最终 CD | 顶点 / 三角面 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 仓库复现配置 | 0.5505 | 0.4291 | 0.4536 | 0.4413 | 105030 / 208718 |
| MeshSuite 基准 | 0.5487 | 0.5375 | 0.5415 | 0.5395 | 104072 / 206609 |

原始结果：`outputs/exmesh/{reproduction,benchmark}/dtu/scan24/`
中的 `metrics.json`、`mesh_metrics.json`、`stats.json`、`train_stats.json`、`profile.json`。
初始化指标分别位于 `outputs/exmesh-validation/initial-mesh-metrics.json`
和 `benchmark-initial-mesh-metrics.json`。公共 DTU 几何采样含随机打乱，末位可能随重新评测略有变化。

训练墙钟时间分别为 1108.7 秒、547.1 秒；期间与其他准备/验收进程有重叠，
不作为独占 GPU 的训练速度比较。进程内训练峰值 CUDA allocated 分别为
2731.7 MiB、1236.5 MiB；`nvidia-smi` 全设备监控还包含其他进程，不能冒充单模型显存。
在所有训练和图像评测退出后，使用公共 profile 命令独占测量 100 次：
全分辨率 7.540 ms / 132.63 FPS，半分辨率 4.729 ms / 211.47 FPS。
两套推理快照均约 113.8 MiB；完整可恢复状态保存在编号检查点。
PLY 和保留独立 UV 索引的 OBJ/MTL/PNG 均已导出。

## 正确性证据与范围

- 固定 UV、非单位相机，逐项对照相邻原版仓库：RGB、alpha、深度、法线、覆盖量、五项损失误差均为零。
  梯度误差不超过原版重复运行的浮点归约噪声；一次 Adam 更新后最大参数差约 `5.8e-11`。
- 实际 CUDA 测试覆盖非零几何/纹理梯度、分裂后 UV/优化器绑定，以及跨分裂事件的连续训练与断点恢复。
- 构建 wheel 后在 `/tmp` 独立解包运行，确认 adapter/trainer 来自该包，能读取实际模型，
  不依赖相邻 ExMesh 仓库；包中包含来源说明及许可证文件。
- 全量回归：**447 passed / 5 failed / 5 skipped**。五个失败与集成前基线完全相同，
  原因是缺少既有 `configs/opaque_2dts_mipnerf360/2dts/mipnerf360/` 配置；无新增失败。
  ExMesh 的八项测试全部通过，其中 CUDA 测试实际执行，未跳过。
- 保留原版居中投影及插值顶点距离的深度定义。相机主点/深度物理语义的修正尚未作为算法变更引入。
- 原版的 `max_shapes=200000` 是分裂选取目标，配对边分裂会超出；实际面数如表，不声称满足硬上限。
- 此处“仓库复现配置”指移植版运行原仓库的 scan24 参数。已完成固定输入的原版数值对照，
  **未声称另行运行原仓库 10,000 步并证明两条随机拓扑训练轨迹等价**。
  PGSR 初始化、训练步数和权重也与论文部分设置不同，不能称作论文表格的精确复现。

对照及回归记录：`outputs/exmesh-validation/parity.json`、`integration-regression.xml`
和 `integration-status.json`；可视化为 `dtu-training.png`、`dtu-reproduction-preview.png`。

## NeRF-Synthetic lego

已由用户确认：独立 PGSR 5,000 步初始化，DA3 预测深度，论文的 ExMesh 8,000 步和
深度/平滑/偏移权重 0.01/1000/1000；验收 200 个测试视图的图像指标及性能。
只使用 100 个训练图像进行预处理。标准 `points3d.ply` 是初始化点云，不作为几何真值。
DA3 全 100 视图联合推理在 12GB 显卡 OOM；用户确认保持原模型/504 分辨率、每批四个训练视图。
该方案改变多视图上下文。关闭 autocast 权重转换缓存并启用可扩展 CUDA 内存段后，
100 份训练深度成功生成，峰值 CUDA allocated 为 8664.6 MiB，推理耗时约 51.6 秒。
模型计算 dtype、权重和输入分组保持原选择。

8,000 步训练及全部 200 个测试视图评测现已完成：

| 场景 | PSNR ↑ | SSIM ↑ | LPIPS ↓ | 顶点 / 三角面 | 渲染 profile |
| --- | ---: | ---: | ---: | ---: | ---: |
| lego | 26.4110 | 0.9278 | 0.0807 | 124080 / 245604 | 5.124 ms / 195.15 FPS |

ExMesh 训练耗时 854.9 秒，进程内峰值 CUDA allocated 为 2151.2 MiB。
独立 PGSR 训练/提取耗时分别为 110.5/7.9 秒；DA3 耗时 51.6 秒，不含模型下载。
profile 在训练与图像评测退出后，用首个测试相机预热五次、计时一百次；峰值 allocated 约 0.318 GiB。
推理快照为 116.5 MiB。编号 `8000.pt` 可恢复训练，`final.pt` 为模型值完全相同的推理快照。
实际导出的 OBJ 几何/UV/面索引与检查点逐项一致，PNG 纹理差异不超过 8-bit 量化误差。

重要限制：独立 PGSR 初始化为 331,831 面，超过原版 `max_shapes=200000` 分裂目标。
保留原版算法后，合并将面数降至 245,604，期间始终未低于分裂目标，实际新增面分裂次数为零。
DTU 训练和独立 CUDA 测试已验证分裂路径，但本次 lego 不是完整自适应分裂效果的充分验收。
没有静默加入网格简化或修改面数预算。若进一步研究 lego 质量，应将“简化粗网格后再训练”
作为单独实验征求用户选择；本报告仅提交当前已确认协议的实测结果。
此外，PGSR 初始化、四视图 DA3 上下文及沿用代码默认的未公开细节均与论文完整设置存在差别，
本次单场景结果不能直接等同于论文八场景均值或精确复现。

原始结果和导出资产位于 `outputs/exmesh/benchmark/nerf_synthetic/lego/`。
准备、失败诊断和验收记录位于 `outputs/exmesh-validation/lego-*.json` / `lego-*.log`；
`lego-test-preview.png` 展示三个测试视图，`lego-depth-preview.png` 展示训练深度先验。
